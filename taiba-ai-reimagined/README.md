# طيبة AI — رواق التعلّم

**واجهة جديدة من الصفر، وليست نسخة ملونة من التصميم السابق.**

رواق يحوّل طيبة من حاوية محادثات إلى استوديو للتعلّم: مساحة سؤال مفتوحة، ودفتر أفكار قابل للكتابة، ومؤقّت تركيز، وورق قراءة مرقّم بدل صفوف الفقاعات.

## افتح النتيجة

**الأسهل:** نزّل المستودع من GitHub عبر **Code → Download ZIP**، فك الضغط، وافتح **Taiba_AI_Riwaq.html** الموجود في جذر المستودع.

لتشغيل ملفات المصدر:

~~~bash
cd taiba-ai-reimagined
python3 -m http.server 4174
~~~

لا توجد حزم npm أو خطوة build مطلوبة لاستخدام النموذج. الخطوط والأيقونات محلية.

## ثلاثة مفاهيم، واختيار مقصود

افتح [concepts.html](concepts.html) لاستكشاف التركيبات الثلاثة، أو اقرأ [توثيق المفاهيم](docs/CONCEPTS.md):

1. **Editorial Intelligence:** مجلة معرفية بأعمدة وفهرس وهوامش قراءة.
2. **Future Intelligence:** مسرح عمل سياقي، شريط أدوات ضيق، ولوحات تتبع المهمة.
3. **Riwaq / Learning Studio — المختار:** مكتب غير متناظر للسؤال والتدوين والتركيز، مع سجل مستقل وتنقّل سفلي على الهاتف.

الفروق تشمل التكوين والتنقّل والهرمية والتفاعل، وليست مجرد ألوان.

## جرّب التفاعلات

- اكتب سؤالًا في ورقة الاستوديو أو اختر بداية من السطور المرقّمة.
- جرّب أوضاع «نفهم / نلخّص / نكتب كود». الردود نصوص توضيحية ثابتة، وليست اتصالًا بذكاء اصطناعي.
- افتح «كيف تتعلّم الآلة؟» لرؤية الكود والجداول والاقتباسات والقوائم.
- احفظ فكرة من الرد مباشرة إلى دفترِك، أو اكتب ملاحظتك بنفسك.
- شغّل مؤقّت تركيز ٢٥ دقيقة، أو استراحة ٥ دقائق. يدعم الوقف والاستكمال وإعادة الضبط.
- افتح «دفتر المحادثات» للبحث والتصفية والحذف.
- من خيارات الرد اختبر الخطأ التجريبي وإعادة المحاولة والإيقاف.
- المسودات تبقى محفوظة عند تغيير الوجهات. أثناء الرد يمكنك مواصلة كتابة سؤالك التالي.
- على الهاتف: تنقّل سفلي بأربع وجهات؛ الدفتر يفتح كنافذة مستقلة؛ المحادثة تستغل مساحة القراءة.
- بدّل اللغة والمظهر من رأس التطبيق. النصوص المكتوبة في المحادثات والدفتر تظل بلغتها الأصلية.
- الجامعة تعرض نشرة زمنية مع التفاصيل وحالة القراءة.
- الإدارة تضم إدارة الطلاب والنشرات و٢٢ مزوّدًا، وحصصًا ومؤشرات صحة تجريبية فقط.
- الحساب يضم بيانات الطالب والتفضيلات وشاشتي الدخول وتغيير كلمة المرور.

## حدود النموذج

البيانات والتعديلات محفوظة في هذا المتصفح فقط، تحت المفتاح **taiba-riwaq-v2**. ملف المرفق يُعرض باسمه فقط دون قراءة محتواه أو رفعه. لا توجد مصادقة فعلية أو قواعد بيانات أو مفاتيح API أو اتصال بخدمات AI أو Cloudflare.

تم التحقق بمتصفح Chromium آليًا. سلوك لوحات المفاتيح الحقيقية، وواجهات Safari وAndroid، وقارئات الشاشة يحتاج اختبار أجهزة فعلية قبل الإنتاج. لم يتم نشر موقع.

التصميم السابق محفوظ في مجلد taiba-ai-design مستقل.
