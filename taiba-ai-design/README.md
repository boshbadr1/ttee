# طيبة AI — مساحة لأفكارك

نموذج واجهة مستقل وتفاعلي لرفيق جامعي ذكي، مبني من الصفر باستخدام **HTML5 + CSS3 + Vanilla JavaScript**، وتوجيهات مهارة **ui-ux-pro-max**.

**واجهة تجريبية فقط:** لا مصادقة حقيقية، ولا قاعدة بيانات، ولا اتصال بخدمات الذكاء الاصطناعي أو Cloudflare. كل الحسابات والأرقام والإعلانات والردود بيانات عرض.

## التشغيل

لا تحتاج تثبيت حزم أو خطوة build:

~~~bash
cd taiba-ai-design
python3 -m http.server 4173
~~~

افتح عنوان الخادم المحلي في المتصفح. يمكن أيضًا فتح index.html مباشرة؛ يوصى بالخادم لتوحيد سلوك الخطوط والتخزين المحلي والحافظة.

## استكشف التجربة

- الصفحة الأولى: تحية باسم قابل للتعديل، وأربع بدايات للمحادثة، وشريط جانبي قابل للبحث.
- اكتب رسالة أو اختر اقتراحًا ثم أرسل. الرد يظهر بمؤشر انتظار وعرض تدريجي، وهو **نص تجريبي ثابت**.
- افتح محادثة «شرح البرمجة كائنية التوجه» لرؤية كود Python وجدول واقتباس وقوائم وأزرار نسخ.
- من قائمة «مساعد الدراسة» اختر «جرّب خطأ في الرد القادم» لاختبار إعادة المحاولة.
- زر الشمس/القمر يغيّر المظهر. زر **EN / ع** يبدّل لغة الواجهة واتجاهها.
- قائمة الحساب أسفل الشريط الجانبي تفتح الملف الشخصي أو شاشة الدخول.
- الملف الشخصي يتيح تعديل اسم العرض، واختيار المظهر، والوصول إلى نموذج تغيير كلمة المرور.
- الإعلانات: تصفية، قراءة التفاصيل، وحفظ حالة القراءة.
- الإدارة: إحصاءات توضيحية، إضافة طالب والبحث عنه وتعطيله، محاكاة إعادة التعيين، إنشاء/تعديل/حذف الإعلانات، وتفعيل مزودي الذكاء الاصطناعي في العرض المحلي.

## التخزين والخصوصية

يحفظ localStorage التفضيلات والمسودات والمحادثات التجريبية وتعديلات بيانات العرض في هذا المتصفح فقط. لا تُحفظ كلمات المرور. المرفقات تعرض اسم ملف محلي فقط؛ لا يُرفع أو يُقرأ محتوى الملف. لإعادة ضبط العرض احذف المفتاحين taiba-demo-v1 وtaiba-demo-language من أدوات المتصفح.

المحتوى المكتوب بواسطة المستخدم وسجلات المحادثات لا تُترجم تلقائيًا عند تغيير لغة الواجهة. تبقى العربية والإنجليزية قابلة للقراءة في الرسائل نفسها.
