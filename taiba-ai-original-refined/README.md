# ✦ طيبة AI — Original Style, Premium Refinement

التصميم الأصلي المحبوب، مصقول: **النجمة الرباعية، البنفسجي الهادئ #7460AF، والأبيض الدافئ #F9F9F7**. نفس الواجهة المألوفة، مع قراءة عربية أوضح وتحسين سلوك المحادثة والكتابة على الهاتف.

## افتح النسخة

من GitHub اختر **Code → Download ZIP**، فك الضغط، ثم افتح الملف:

**Taiba_AI_Original_Style_Premium_Refinement.html**

هذه نسخة مكتفية ذاتيًا تتضمن الخطوط والتصميم والتفاعلات. ولتشغيل المصدر:

~~~bash
cd taiba-ai-original-refined
python3 -m http.server 4175
~~~

لا تحتاج تثبيت حزم npm أو خطوة build. يمكن فتح index.html مباشرة أيضًا؛ استخدام الخادم يوفّر سلوكًا أكثر اتساقًا للتخزين والحافظة.

## ما تم الحفاظ عليه

- النجمة الأصلية في الشريط الجانبي ورأس الواجهة وتجربة الترحيب.
- التحية باسم الطالب: «هاي يا بدر 👋»، ثم «إزاي أقدر أساعدك النهارده؟».
- الألوان الأصلية والأسطح الهادئة، مع مظهر داكن متناسق.
- الشريط الجانبي وسجل المحادثات والبحث والمقترحات وحقل الكتابة البسيط.
- الدخول، وتغيير كلمة المرور المؤقتة، والحساب، والإعلانات، والإدارة.
- إدارة الطلاب، والنشرات، و٢٢ مزوّدًا تجريبيًا مع البحث والتصفية.

## التفاصيل التي تحسّنت

- IBM Plex Sans Arabic محلي بأوزان فعلية، وInter للإنجليزية.
- نصوص محادثة أكبر، وتباعد أسطر وفقرات أوضح، وفقاعات مستخدم ناعمة.
- كود وجداول قابلة للتمرير داخلها، وقوائم واقتباسات وعناوين ونسخ الرد.
- حقل كتابة ثابت في بنية التطبيق، دون إعادة إنشائه أثناء الإرسال.
- تحديث رسالة المساعد فقط أثناء العرض التدريجي، مع احترام موضع القارئ.
- قياسات viewport موحّدة؛ جسر Visual Viewport يعمل عند وجود تراكب حقيقي فقط.
- أزرار إرسال وإرفاق بسطح لمس مريح، وحجم نص حقل الكتابة ١٦px على الأقل.
- اتجاه الحقل الفارغ يتبع لغة الواجهة، والنص المكتوب يدعم العربية والإنجليزية تلقائيًا.

اقرأ [KEYBOARD_FIX_NOTES.md](KEYBOARD_FIX_NOTES.md) لتفاصيل القياس والتركيز والتمرير وحدود الاختبار.

## جرّب

1. اختر اقتراحًا أو اكتب رسالة وأرسلها.
2. واصل كتابة مسودة أثناء الرد؛ الحقل لا يُعطّل.
3. افتح «شرح البرمجة كائنية التوجه» لمشاهدة الكود والجداول.
4. من قائمة مساعد الدراسة اختر «جرّب خطأ في الرد القادم»، ثم أعد المحاولة.
5. جرّب المظهرين، وفتح/إغلاق سجل المحادثات، وتغيير لغة الواجهة.
6. من الحساب جرّب تعديل الاسم والدخول ونموذج كلمة المرور.
7. من الإدارة جرّب إضافة طالب وتعطيله ومحاكاة إعادة التعيين، وإدارة الإعلانات والمزوّدين.

## التحقق والحدود

[نتائج الاختبارات](docs/TESTING.md) توثّق فحوص المحادثة والنماذج والتباين، ومحاكاة اللمس والـ viewport. **لم يتم اختبار هاتف فعلي أو محرك Safari.** يبقى اختبار iPhone Safari وAndroid Chrome بلوحتي مفاتيحهما الفعليتين مطلوبًا قبل الإنتاج.

هذا نموذج مستقل ببيانات عرض وردود ثابتة. لا توجد مصادقة حقيقية أو خدمات AI أو قاعدة بيانات أو اتصال بـCloudflare، ولم يُنشر موقع. المرفقات تُعرض بأسمائها فقط دون رفع أو قراءة. التفضيلات والمسودات والبيانات التجريبية تُحفظ محليًا تحت المفتاح taiba-original-refined-v1؛ اللغة تحت taiba-original-refined-language.

المحتوى المكتوب في المحادثات يبقى بلغته الأصلية عند تبديل لغة الواجهة. قيود المتصفح قد تمنع التخزين أو النسخ في بعض سياقات الملفات المحلية؛ توجد رسائل بديلة للنسخ وتبقى الجلسة قابلة للاستخدام.
